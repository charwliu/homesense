# 灯光供电、调光及窗帘通道清单

核对日期：2026-10-24。依据NGR当前运行的 **rev52** 配置、已发布桥计划和接管验收记录整理；本轮只读核对，不发送设备动作。地址均为十六进制，`03-4`表示模块`0x03`第4路。原始配置、稳定模块UUID、配对和凭证留在私有目录，本文只记录审核后的通道摘要。

原rev37物理表和rev41候选说明已由以下现行关系替代，不再把历史推定当作当前配方。Control4原楼层B1／1层／2层分别对应现在的1／2／3层。**Front已从房间目录移除**；原Front三路归入1层设备间，按用户决定保留，实际用途不作为接管阻断项。

## 当前范围与证据边界

- 7个R818、5个AD8，共96路照明／供电／风机输出；3个C4-DIN-PRO窗帘模块和28块TS6-86面板另列。
- 当前有14组、41盏多路组合逻辑灯，另有6盏常规供电／调光组合灯及20路其余照明、风机或保留输出。组合卡片数不等于物理灯具数；共享通道在表中重复列出。
- Apple「家庭」现有62项灯光／开关、81项场景、11项原生窗帘，分布在原已配对的两座桥；原始供电／调光资源不会额外生成同名灯具。隐藏原始输出可由已发布场景使用，不能把“原始目录隐藏”解释成不可控制。
- 下表证明当前配置与发布范围，不把配置配对自动当作实物接线确认。主卧3×3供电／调光矩阵及书房、画室有明确的逐路现场记录；其他房间保留既有限定验收范围，待补项目见[接管清单](control4-takeover-checklist.md)。目前打印表38／54项已核对，其余项目不由本轮文档更新补签。
- 起居室仍属3层。四路保留输出为设备间`01-1`、`02-1`、`13-1`及阳光房`14-2`，不再要求补查用途。

## 面板左右名称与配电间位置

面向配电柜，原IMG_6887对应左侧、IMG_6886对应右侧；已确认的模块位置沿用原柜体定位记录。房间改名、逻辑灯合成不表示物理模块移位。可打印PDF按各自页脚版本留存；当前软件配置关系以本文为准。
