# 场景状态推断

场景按完整、新鲜且没有待决写入的灯光开／关组合判定。唯一组合直接匹配，不要求亮度等于配方目标；相同组合对应多个模式时，才使用可靠亮度区分。实际亮度单独显示。

`unique_light_on_pattern` 只匹配开关组合；`power_pattern_then_profile_level` 在组合歧义时进一步比较明确的亮度目标。全组明确关闭时优先归零，不在多个全关配方间猜选。

亮度区分使用已定义读回域的 AD8 整数百分比，不套用通用容差。反馈缺失、过期或不能唯一匹配时保持未知；供电关闭时非零调光寄存器不表示灯亮，供电未知不能生成亮灯证明。

状态推断仅建立当前连接的投影，不导入原 Control4 保存变量，也不替代规则来源审核或运行权限。LED 输出继续单独准入、校验和审计。

## 省略目标

`reconciliation.omitted_targets: "preserve"` 使场景只操作定义明确包含的灯。缺省或 `"off"` 使用组内完整目标向量。策略需在启用物理推断的组中显式配置，不按场景名称自动选择。

状态仍采样审核后的成员并集；省略目标与缺失反馈不同。多个保留模式同时匹配时不按顺序猜选；亮度只使用冲突候选都明确指定且确有差异的通道，不把省略值当零。权限、代次、反馈租约及截止检查在准入时再次执行。
