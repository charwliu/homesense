# 原窗帘规则的禁用转换契约

导入器生成可审核的禁用规则，不连接现场或自动启用。导出成功不代替原程序、变量生命周期、设备绑定及窗帘校准的审核。

## 转换范围

默认转换保持拒绝原 `IF_STOPPED`、`IF_MOVING`、`SET_LEVEL_TARGET` 和 `STOP`。显式 opt-in 的每个电机目标必须具有对应源事件／精确 XML 指纹／源目标的映射审核，以及当前配置中已启用的稳定逻辑 ID 和方向／停止校准。子代理必须映射到既有父控制器的逻辑 ID，不能另建一个独立电机模型；来源身份关系不代表方向或反馈审核。

`SET_LEVEL_TARGET` 仅接受标记为 INTEGER 的原枚举形状（或合法 STRING 形状）的 `LEVEL_TARGET_NAME` 静态字面值 `Open` 或 `Closed`，映射为逻辑 Open／Close；INTEGER 标记不解释为数值百分比，不补造 `Close`、数字百分比、动态参数或依据显示文本猜测动作。`STOP` 必须无参数，保留明确 Stop。输出保存 source 标签、节点顺序、原条件、复合表达式及 Else；仍为 `enabled:false`、`automatic_execution:false`。方向只在配置解析中经稳定逻辑 ID 与审核校准解析，未经校准的逻辑动作不能进入执行。

## 三值条件与独立证据

窗帘 Moving／Stopped 使用独立证据通道，不能把估计塞进注明 Actual feedback only 的灯光反馈，也不能由上次命令、输出吸合或停止键颜色冒充实际运动。没有可信样本、处于待决、越代、撤权、断连、重启、过期或未知时，两个分支都不执行。包含未知窗帘读的复合 guard 整体保持 Unknown，不能借另一个布尔项的决定值转入 Else；既有非窗帘条件语义保持不变。

默认谓词仅采用实际证据。当前所有者没有可靠实际运动提供者，因此此默认谓词不能作为已启用规则的依据；仅总体规则审核文字也不够。使用命令／计时推断必须逐谓词显式审核、限定逻辑设备和有效时间，并要求该设备已安装明确审核的窗帘模型；一个已审核范围的决定不自动扩展到其他范围。实际值和推断值都记录 provenance。

所有推断复用当前 Admission 的唯一窗帘 owner，计时从真实持久 Written 开始。排队命令不成为运动事实，新的待决动作使规则条件暂未知；计划接受时再次验证同 boot／全部代次、主体权限、当前运动依据与读集，旧状态计划不能通过变量 CAS 或队列等待继续执行。失败与恢复不重放旧命令，也不从源保存值初始化运动。

## 手动和原 guarded 程序

原 guarded 规则保留其条件，不能悄悄改成每次直接执行。独立主动手动 Open／Close／Stop 则每次明确提交，经原权限、校准、连接和容量门禁，不受规则 guard、估计终态、上一命令或 LED 颜色限制。取消旧停止键变量翻转并保留新活动提示的决定只适用于已审的特定改写，不改写其他程序中的变量或 Else。

变量初值、保存值、外部 writer、驱动事件归属、LED 执行权及其他房间的方向／行程仍待逐项确认。此处不会替用户选择这些值。原归档与真实逐节点重导出日志只保留本地；公开用例使用合成数据。

## 导出与发送边界

独立 `motor-event-draft` 工具仅读取项目 XML、目标配置、绑定和逐事件审核文件，输出单个禁用草稿，不安装、发布或执行。审核文件必须匹配配置版本，包含 `source_key`、`source_xml_sha256`、`source_target`、`device` 和 `mapping_review`；父控制器和唯一窗帘代理必须复用稳定逻辑设备。源项目和审核文件应留在部署方本地。

```sh
cargo run -p homesense-import --bin motor-event-draft -- \
  PROJECT.xml SOURCE_KEY CONFIG.json BINDINGS.json REVIEWS.json --simulation
```

启用的精确谓词范围由当前自动化配置生成，调用者不能提交一个陌生谓词来获取推断证据。即时规则、面板规则和延迟规则使用同一捕获／接受门禁；延迟动作仍遵守其原调度和预算，不能通过旧捕获隐含延长条件有效期。

已准入命令在真正选择发送前再次核对条件有效期、全部代次、权限、当前所有者状态和精确排队身份。另一主体即使发来相同 Open 动作，也会使旧依据失效。本批自身已接受／真实 Written 的动作可推进其见证，但不延长原期限；发送期间发生的外部变化不能被本批 Written 吸收。失效命令留下取消回执，不重新计算 Else 或重放。准入时已经提交的变量及已经写出的动作不因此回滚。

审核规则内的显式 Open／Stop／Close 保留源节点次序；独立手动 Stop 保留安全优先级并取消旧排队运动。HAP 普通灯光入口仍不接受电机命令，自动化电机动作独立复核当前校准，再交给既有唯一持久队列与发送者。
