# Control4 控制接管待办

目标：由 HomeSense 统一承担已纳入范围的面板、灯光、窗帘、排气／风机、回家／离家和关联 LED 控制。按清单逐项完成，软件通过、现场通过与执行归属切换分别记录。

本轮状态：2026-10-17 已由本聊天完成 Linux 交叉编译和隔离复验，发布 rev18／新 ELF，覆盖安装 App build17；实体面板执行仍为 0／0，网关端口及 Control4 尚未切换。

切换策略已按用户最新指示调整：EA-5 保持供电、Control4 工程不修改；只改变 `192.168.0.10` 的 TCP 监听端口，使 EA-5 的旧连接失效，HomeSense 改连新端口。端口变更本身不证明旧会话已断开或没有其他同总线写入者；必须先核对隔离，再启用 HomeSense 实体执行。候选未合格前不下发端口或配置变更。当前工程备份可作为补充证据，不以 Composer 可用性阻断软件工作。

实体执行的配置门是 `keypads[].event_control.owner=homesense`，不是 `automation.rules` 的数量。切换前必须验证实际运行配置的执行面板／键为 0／0；全屋接管候选为 28／168，并须另核对运行时归属和旧控制器总线写入路径隔离。最终 schema 使用准确的 `legacy_writer_isolated` 声明；旧 `legacy_controller_offline` 字段及其 armed.v1 候选不得用于此端口隔离方案。只有证实旧会话断开且 `.11` 无旁路写入后，才能把隔离声明设为真。

用户已确认没有音频功能依赖；音频不列为本轮接管缺口。
