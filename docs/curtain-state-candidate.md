# 窗帘状态模型与统一运行时

软件入口已接通：同一个 Admission 为每个逻辑窗帘持有唯一轨迹，HAP、Web、直接手动请求及显式候选句柄共用它。现有现场配置未启用本候选；本轮没有部署、启动现场服务或实物动作。原系统配置、控制范围及未批准源程序保持不变。

## 动作、位置和停止键

Opening、Closing、Stopped 是互斥的动作估计；Open、Closed、Intermediate 是独立位置类别。缺少依据表示未知，不增加第四种命令。实际模块反馈与推断分开：当前协议没有可靠运动／位置读回，参数查询、完整网络写出、虚拟动作复位和进程退出都不是实际停止。

每个有效的主动 Open、Close、Stop 经原校准、权限、连接、容量和代次门禁提交；不按估计终态、历史同方向或 LED 颜色去重／禁用。外部手动运动不能可靠侦测，可能使缓存估计不准；新手动请求仍重新发送。停止按钮始终可在原门禁下操作。

`stop_led_active` 是独立的停止键活动／颜色提示，不是电机位置，也不用于阻挡手动停止。旧停止键状态翻转编码不作为新模型初值或持久状态：记录最后成功 Written 命令、运动估计、位置估计及活动提示。重启不从源保存值猜测位置，不读取或修改原变量。

## Written 计时和百分比

`Timing` 的 `open_travel_ms`、`close_travel_ms`、`stop_led_idle_ms` 通用默认均为 `None`；有值须为 1 毫秒至 24 小时。互锁参数不能替代行程。具体本地近似值与批准范围仅保留私有建议，不自动应用现场。

Admission 在完整、持久 Writing → Written 后直接向模型交付同一单调时刻，不以接受或首次读状态时间重新启动计时。日志后续转为 Observed 时仍保留已经核实的 Written 锚点，更新时间不冒充写出时间；首次客户端读取已晚于行程时直接显示估计终态。

已知起点和方向全行程允许按恒速假设计算百分比，以百分之一为精度并夹在 0–100%，来源始终是 Inferred。未知起点的中途 Stop 只保留 Intermediate，不补 50%。反向按新命令 Written 边界计算旧运动再从该估计起点继续；连续 Stop 不重复累计运动。重复同方向命令重新计算本次完整方向行程，不因缓存终态立即“到位”。

接受新方向或 Stop 时，旧终态／闲置提示不能抢先生效；旧健康运动及活动提示保持到新命令真实 Written。如果两个动作先后接受、旧命令仍在 Writing，旧命令完整 Written 后可以建立真实写出轨迹，但不能完成更新的待决动作。后续有效 Written 才切换轨迹与计时。

## 唯一所有者和生命周期

轨迹属于逻辑设备，不属于客户端主体或 HAP／Web 实例。`Candidate` 是同一所有者的诊断／显式手动句柄，不再持有独立计时器；同设备重复安装相同计时复用既有模型，冲突计时拒绝，不能修改已发布 LED 绑定。`cached` 仅表示其 `captured_ms` 时刻；当前状态须 `refresh`。

命令仍保留实际请求者的授权和原入口范围，没有管理员代发。配置、连接、控制代次或 boot 改变时清空旧轨迹；失败、不确定、取消、丢失收据和授权失效不能恢复旧计时。若只撤销旧 Written 来源 A，A 的估计／LED 输出失效，但另一个合法主体 B 已准入的待发描述仍保留；B 真正 Written 后建立 B 的新轨迹。传输失败或整体换代则废弃全部旧描述，不重放、重试或自动补 Stop。

取消请求 future 只请求失效估计，不把客户端离开视为实际停止；同步失效通知使用有界邮箱，过载时诊断缓存仍立即清空，共享失效通知可能无法入队。确认已发生的外部干预应在所有者可用时重新核对失效结果，不能凭旧缓存继续自动判断。

核心 `observe` 仅预留给独立可信实际提供者；当前所有者不调用它。自动条件默认实际 Stopped，显式单个候选的 ReviewedLocalEstimate 仅提供标明推断的诊断谓词，不启用源规则。手动入口从不调用该自动条件门禁。

## 可选配置与逻辑 LED

在启用且已校准的 motor 设备上添加 `curtain_state` 才安装发布模型：

```json
{
  "curtain_state": {
    "open_travel_ms": 1000,
    "close_travel_ms": 1000,
    "stop_led_idle_ms": 200,
    "evidence": "synthetic software review only",
    "reviewed_at_unix_ms": 1,
    "leds": {
      "open": ["open-led"],
      "close": ["close-led"],
      "stop": ["stop-led"]
    }
  }
}
```

以上数值与名称仅为合成软件夹具；无字段的旧配置不隐式安装估计或 LED 输出。每个角色可对应多个固定逻辑 LED，均须为已启用、可编码的手动模式 keypad。设备配置拒绝重复／跨窗帘共享绑定；自动化文档还拒绝与启用的 indicator_links、定时场景、规则及可调用即时场景中的 LED 输出重叠，包括未命中的条件分支。禁用规则只作为审核资料保存，启用时仍须重新验证。

运动中 open／close LED 绿、stop LED 红；估计 Closed 为 open 红／close 绿，估计 Open 相反；中间／未知位置 open、close 都红。成功 Stop 或估计到位后，stop 提示保持红至配置的延迟结束再绿。故障／未知 stop 活动不输出伪造停止绿灯。

LED 边沿由同 Admission／Arbiter／持久队列／TransportOwner 经手动模式校验输出，保留最近成功 motor Written 的实际主体及因果命令 ID。该固定审查效果不开放客户端直接 LED 权限；每个边沿最多尝试一次，容量或授权失败不自动重试。颜色意图、准入和真实 LED 反馈不是同一概念，当前没有实际 LED 读回。

## HAP 与 Web

被 HAP 桥选中的窗帘现在发布为每路一个原生 WindowCovering，包含 CurrentPosition、TargetPosition、PositionState 和可选 HoldPosition；原三个 momentary 开关的 AID／IID 仍保留在身份库中，不复用，桥图变更由 HAP 配置号通知已配对客户端。旧三开关适配器只供既有隔离测试，不与原生窗帘同时发布。当前代码尚未部署到现场。

自动化服务的 HAP 桥只发布场景和窗帘（另有协议要求的桥配件）：单独灯、组合灯、Away 开关和实体面板按键都不发布。旧桥接计划即使仍含 `lights`／`panels` 选择，启动路径也不会创建这些配件；后续整理计划时应将这两项置空，新的计划可直接省略。HomeSense App 和自动化中的灯光控制不受此 HAP 展示策略影响。

Apple Home 的百分比是 **HomeSense 的推断值，不是电机位置反馈**。独立可信位置不存在时从 50% 起算；已核实 Written 的打开／关闭指令沿本次起点至 100%／0% 的线性模型推进，10 秒没有新的 Written 停止或反向指令即显示端点。手动停止保留当时的估算位置。重启、失联或估算所有者失效后重置为 50%，不会用旧位置冒充实际反馈。已有 `curtain_state` 审核配置若与 10 秒行程不一致，原生 HAP 启动会拒绝，需先一致化配置。

已有审核模型时，HAP 复用其完整计时，包括停止键提示延时，不以空值覆盖 LED 策略或另建冲突的轨迹。行程不一致会在注册轨迹和发送电机指令之前拒绝。

HAP 目标 0%／100% 分别发送一次校准后的关闭／打开；1–99% 按当前推断位置选方向，以同一 10 秒行程估算抵达时间，在前一方向命令真正 Written 后安排 STOP。若期间出现新的待写入动作或新的 Written 指令，旧自动停止不会再发；STOP 准入仍由原请求者权限和配置版本约束，失败不会盲目重试，实际停位最多有 HAP 刷新间隔及总线写入延迟。HoldPosition=true 直接请求 STOP，false 不产生动作。上述定位是估算，不能作为精确行程控制或独立安全限位。

Web 的独立 `motor_estimate` 包含明确 Inferred 来源、运动、位置、可选百分比、待决动作、停止键活动提示与最后真实 Written。原 `observed` 保持实际模块数据。WebSocket 将模型变化纳入状态推送，不修改实际 Feedback 的序号或历史；重连仍只读完整快照，不重放命令。三个手动按钮不受估计位置／颜色限制，原权限、忙碌和断流门禁仍适用；HTTP 同 request_id 保留既有幂等收据语义。

## 验证与剩余范围

隔离源码包含恒速模型、真实 Written 边界、同设备跨主体轨迹、先接受两动作再写出、撤权移交、故障／换代、LED 边沿与独占校验。联合用例建立实际 localhost 加密 HAP 会话、Web HTTP 登录与鉴权 WebSocket，从 HAP 主体 A 打开，再由鉴权 Web API 主体 B 关闭、停止及再次停止；内存总线核对 motor 和 LED 字节，验证 Web 403 范围与同 request_id 不重放。WebSocket 复核活动变绿通知且实际反馈序号未变；这不是浏览器或 LAN TLS 实机验收。前端用例验证推断标签、未知不补百分比和手动 Stop 可用性。

这些是软件证据；实际电机近似行程、物理 LED、手机／中枢持续连接和现场配置启用仍待限定验收。原项目变量／条件和事件执行归属不因手动入口接通而自动获批，墙面板原自动规则仍保持禁用。
