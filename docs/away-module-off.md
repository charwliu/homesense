# 离家与逐模块关闭

离家通过统一执行器关闭已审核的模块范围，供原生管理 API、HAP 和实体按键调用。全屋关闭复用同一执行链，包含登记的灯光、供电和排风扇，不控制窗帘。

## 执行顺序与反馈

每次先发送一个模块的整模块关闭，接收其八路所需反馈后推进下一模块。R818 使用 `AE ID 00 F2 EE`，AD8 使用 `AE ID 00 00 EE`；模块地址不是广播地址，不能将普通通道零当作可单路操作的通道。

关闭遇单模块超时后仍继续关闭其余模块，后续轮次只重试失败模块。迟到的真实关闭反馈可移除待重试模块；已确认关闭但反馈变旧的模块只补读，不重复关闭。全屋开启在失败时遵守自己的停止策略，不能直接套用关闭流程。

| 边界 | 行为 |
| --- | --- |
| 总期限 | 默认10秒，所有阶段受同一截止限制，进度与新反馈不续期 |
| 关闭轮次 | 最多3轮，轮间200ms；不增加第四轮 |
| 发送排队 | 最多2秒，仍受更早的总截止限制 |
| 单模块回复 | 最多1秒；R818保留最多500ms接收窗口，完整反馈到齐即可推进 |
| 补充查询 | 单次最多250ms，原查询重试合计最多500ms |
| 完成 LED | 真实关闭确认后最多2秒发送，仍不超过原操作总截止 |

未轮到发送的查询不算设备超时。主动回复与补查共用唯一总线所有者及换向间隔，部分回复不能冒充完整确认。三轮耗尽后可在剩余预算内只补读，再冻结失败通道；后来反馈更新当前状态，不改写历史失败结果。

成功要求全部原始输出在本次相应写出之后有有效关闭反馈。供电继电器关闭不能替代 AD8 输出归零，未回复不等于关闭。Written 仅表示流写完；部分写出保留不确定结果，恢复不重放旧票据。

## 进度与指示灯

接受回执中的 `commands` 只包含当时已提交的模块票据和当前键提示；后续模块沿同一 `operation` 追加。客户端按操作进度及终态判断结果，不从首个数组长度推断范围。

`server_retry` 公告轮次、间隔、回复窗口与总期限。完成／失败主动唤醒 WSS 订阅者，每次交付重新校验凭证和可见范围，App 不自行重试。

墙上离家键立即提示红色，再发送关闭命令；全部关闭确认后变绿。提示不阻止有效全关，未确认、取消或失败不写成功绿灯。其他联动 LED 按对应真实反馈更新。

## 配置与权限

`away_off` 缺省不可用。启用前审核模块全部八路用途、绑定、支持型号及明确的非照明负载许可。模块以稳定 `module_id` 解析地址，所有输出须启用并在授权范围内。

```json
{
  "away_off": {
    "enabled": false,
    "hap_expose": false,
    "review_evidence": "review of the complete operation",
    "active_execution_policy": "cancel_affected_lighting",
    "modules": [{
      "module_id": "lighting-module",
      "devices": ["lamp:1", "lamp:2", "lamp:3", "lamp:4", "lamp:5", "lamp:6", "lamp:7", "lamp:8"],
      "review_evidence": "review of all eight physical ports"
    }]
  }
}
```

这是片段，须经完整配置校验、草稿和发布流程。`cancel_affected_lighting` 原子替代相关排队控制，防止旧时间线再次点灯；其他负载和安全 STOP 保留。`require_quiescent_runtime` 则在存在未完成任务时拒绝，语义不同。

主体需满足完整范围权限，组合灯隐藏供电只从逻辑灯授权推导，不能借单个继电器权限旁路。权限、来源、配置和传输代次在准入及派发重查，每路影响与命令审计保留。

## API 与 HAP

- `GET /api/v1/away-off`：当前主体可用性。
- `POST /api/v1/away-off`：仅接受当前 `revision` 字符串与 `request_id`，客户端不能给定替代模块范围。
- 请求使用 HTTPS 身份、Origin／CSRF 和持久幂等收据；结果未知不自动重试。
- `hap_expose` 明确启用后由覆盖完整范围的桥发布瞬时动作，使用真实已配对控制器授权；写 `true` 执行，写 `false` 只复位，不反向开启。
- 独立全屋场景及重复触发限流见[HAP 全屋动作](hap-room-all-actions.md)，实体绑定见[面板离家](keypad-away.md)。

## 本机模拟

模拟器在模块回复前随机等待3～20ms，同模块应答连续写入；9600／8N1线速另计，八个五字节帧约占41.7ms。故障通道不回复，R818仍逐通道查询。延迟与缓冲模型用于验证调度，不直接证明现场电气碰撞的原因。

现场已完成范围及长期观察见[接管结项](control4-takeover-checklist.md)；验收原始配置与日志留在私有目录。
