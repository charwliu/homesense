# ADR 0001：原生 Rust HAP

## 决策

HomeSense 在 `homesensed` 内运行原生 HAP，使用 `homesense-hap` 封装配件、身份存储、反馈投影和运行时接线。HAP 不经过独立桥接进程或管理 HTTP 转发，所有写入进入统一准入与唯一传输所有者。

工作区使用 `vendor/hap` 的受控源码。上游固定来源与许可证见该目录及 `probes/hap-rs/`；依赖由锁文件约束。第三方代码保持自己的许可。

## 实现约束

- 配对、控制器权限、稳定 AID／IID 与配件图持久保存，重启不重建身份。
- 原始 HAP 读写回调通过异步受理接口接入运行时，控制目标不提前覆盖实际反馈。
- 加密流处理分片、短写、认证记录与会话边界；背压、撤销、取消和存储错误明确处理。
- 配件图变更维护持久配置编号，注册失败不能服务半张图；身份／配对变化与当前权限重复核验。
- 服务生命周期和网关恢复保留同一身份，不重放旧控制。

## 验证与使用

配对、加密读写、订阅、权限、重启身份及故障路径使用本机回环验证；现场兼容性由对应范围的验收记录确认。测试与探针不上传部署目标。

HomeSense 支持单桥发布灯光、风机、场景和窗帘，范围由显式桥接计划选择。桥显示名称可编辑，内部身份和配件标识保持稳定。房间分配见[HomeKit 房间接口](../homekit-room-placement.md)，用户操作见[App 指南](../../apps/HomeSense/README.md)。
