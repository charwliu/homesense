## A4 反馈事件投影

ObservedEvents 接收实际 HAP accessory handles 和 LightBinding，校验 AID、On／Brightness IID 与能力，再将 StateStore 的已确认反馈投影到 set_observed_value。只推送变化的特征值；desired、pending 结束、重复反馈及 stale 不生成虚假状态通知。断线清除去重缓存，恢复后相同有效值可重新通知；过期快照不推送。

投影器跟踪 boot ID 和严格连续的事件序号。首次使用、断档、重复／旧事件或发布被中断后必须显式 resynchronize；重新同步可重发当前有效状态。运行时须先发布对应读取快照，再调用投影。两个特征通知并非网络原子事务，重复通知和中途失败通过重同步收敛；尚未解决上游事件队列背压或加密会话发送保证。

## HAP 加密发送的短写修复

检查事件背压时发现上游 poll_outgoing 在 Pending／短写后丢弃尚未写完的明文，且加密写入没有保留未完成的密文记录。当前保留待发送明文及偏移，RecordWriter 缓存一个最多 1042 字节的记录，完整写出才确认对应最多 1024 字节明文。Pending 后续写同一密文，不再次加密或增加 nonce；零字节写入明确失败，加／解密计数器耗尽拒绝回绕。

2 项新增候选测试覆盖 7 字节短写与反复 Pending、2500 字节数据的独立记录解析与解密、零写入和 nonce 耗尽；候选共 17 项库测试加 8 项探针通过，workspace Clippy 和格式检查通过。发送／接收队列目前仍未设容量限制，慢客户端断开、读取分片以及完整加密会话端到端仍待完成，未启动网络服务。

## HAP 出站容量与会话清理

OutputSender 使用共享的有界 sender，最多 64 个排队项，合计 1 MiB，单项最多 256 KiB。发送中的明文仍计入字节预算；密文续写另保留最多 1042 字节。克隆事件发送端不会增加 channel 保留槽。满队列、超限或接收端关闭使输出进入不可恢复的终止状态并唤醒传输任务；连接必须重新建立，不默默丢通知后继续。

HTTP 和加密传输改由同一会话任务管理，一侧完成时释放另一侧，然后移除该连接的事件监听器。4 项新增候选回归覆盖 sender 反复克隆仍有界、终止唤醒、出队后仍计入预算、释放归还预算、单项超限、接收端关闭，以及 100 次监听器注册／移除后的捕获释放。候选共 21 项库测试和 8 项探针通过，workspace Clippy／格式检查通过。真实慢 socket 的整会话关闭验收、入站队列限制、全局连接数、超大配件列表和 HTTP 响应／通知并发排序仍需验证；当前不是全链路内存上限证明。

## HAP 入站记录与缓冲

RecordReader 替换原先依赖整包长度相等的接收逻辑，支持任意拆分和连续记录合包；每次先读完现有明文。密文缓存最多 2083 字节，明文缓存最多 1024 字节；超长记录、认证标签失败和半包 EOF 返回错误并使读取器进入终止状态。解析循环有步数上限并主动唤醒，避免连续空记录占用一次 poll。StreamWrapper 尊重 ReadBuf.remaining，已有缓存不等待下一条网络消息。

入站明文 channel 改为单发送者有界队列，最多 64 项，每项由固定 1536 字节读取缓冲产生；容量耗尽终止连接。3 项新增候选测试覆盖 1/2/7/1042/4096 字节供给、已有内容的小 ReadBuf、多记录独立加密数据还原、所有截断位置、错误标签／长度、失败后拒绝继续，以及包装层缓存续读。候选共 24 项库测试加 8 项探针通过，workspace Clippy／格式检查通过。尚需实际 TCP 加密双向测试、Pair Verify 明文至密文切换、全局会话预算和 iPhone 验收。

## HAP 会话预算与 Pair Verify 输入检查

每个 HAP 服务监听器最多 32 个并发连接，超出即关闭新 socket；许可随会话清理归还。未认证连接从接入起最多 60 秒，认证完成后的空闲连接保留用于事件订阅。监督函数在 HTTP／传输一侧结束或认证期限到达时取消另一侧。两项回归验证未认证超时释放与已认证连接跨期限保持；32 连接的真实并发压力测试仍待执行。

Pair Verify 改用有界 TLV 解码：64 KiB 请求体、5 秒读取超时，拒绝截断、重复字段及错误 State 长度；公钥必须恰好 32 字节并通过 X25519 contributory 检查，M3 必须至少包含 16 字节标签。Finish 消费一次性临时会话，失败不会保留它继续重试，交付会话失败也不报告成功。3 项输入回归验证分片 TLV、恶意长度、公钥和短密文无 panic；此 checked decoder 目前接入 Pair Verify，其他认证端点仍待迁移。候选共 33 项库测试加 8 项探针通过，workspace Clippy 和格式检查通过。正常完整 Pair Setup／Pair Verify 交换与 iPhone 验收仍未完成。
