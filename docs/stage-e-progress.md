## HAP 退出结果只消费一次

Endpoint 的 JoinHandle 改为可消费所有权：finished 取得成功／失败／JoinError 后清除句柄，shutdown 仅等待仍拥有的任务，避免监督器读过结束结果后再次 poll 同一 JoinHandle。等待被 select／timeout 取消时不移走句柄，关闭仍会 abort 并等待任务结束。3 项端点测试与 3 项统一 HAP/Web 回环通过，含结果消费后清理、取消等待后关闭和原端口冲突门禁。此修复是独立降级的生命周期前置，尚未改变监督器故障策略；未部署，EA-5 不变。

## 有状态场景互斥组：运行时基础

自动化 schema 1 新增显式 `scene_switch_groups`，默认空；每组引用专用持久整数变量、至少两个场景成员、各自关闭场景、可选重置场景和审核证据。成员正整数值表示本地选择，0 表示无选择；未知不初始化为 0，也不当作 EA-5 的实时变量。组 ID／变量／成员及取值不得歧义，所有引用必须已启用且审核，不能仅根据名称或灯光目标重叠自动建组。

`SceneWrites` 接受显式 true／false／仅订阅三种输入。true 选择本场景并清除组内其他选择；同值 true 为幂等，不隐式反向切换。false 只关闭当前被选择的成员，其他成员 false 不影响活动场景；未知时 false 拒绝。切换新场景只执行新场景目标，不自动添加旧场景的关闭序列；关闭当前场景执行其明确的 `off_scene`。重置场景执行自身目标并清除本地选择。同批开启同组多个成员，或同组重置与开启冲突，均在输出前拒绝。
