# 窗帘统一操作规则

打开、关闭和停止使用明确命令，经过权限、方向与停止校准、准入、审计及传输检查。估计全开、全关或静止不抑制新的主动请求；配置为同向再次停止的实体／六键入口由服务端统一判定，详情和 HAP 保持明确动作。

位置估计从完整成功写出的命令开始，每个窗帘独立配置开、关行程。互锁吸合时间不等于运动行程。已知起点才计算中途百分比，未知起点保持中途／未知，不补造50%。

STOP 写出或估计到位后按配置结束停止提示；独立停止按钮仍可用。重启、连接／控制代次变化或可信来源失效清除旧估计，不重放动作。电机可被系统外操作，因此位置始终标注估计来源。

保留各房间的布局、模块 ID 和通道，方向、停止与行程分别审核。现场行程按已确认参数配置，不通过复制其他房间参数自动完成校准。

详见[状态模型](curtain-state.md)、[同向再次停止](native-keypad-motor-press.md)和[规则导入](motor-rule-import.md)。
