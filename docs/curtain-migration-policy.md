# 各房间窗帘迁移规则

2026-10-15 用户明确采用统一操作模型。本页规定迁移目标，当前不启用墙面板规则、不发布配置或操作设备。

每次主动点按打开、关闭或停止，都提交对应的明确命令，继续经过权限、方向和停止校准、准入、审计及传输门禁。估计全开、全关、运动中或停止，都不抑制新的主动请求。

估计只从成功 Written 的命令开始。每个窗帘分别配置开、关行程时间；到期为估计终态，不能作为硬件位置反馈。中途 STOP 只有在起始位置和行程时间均已知时估计百分比，否则保持位置未知。STOP 成功写出或估计到位后，停止提示延时 2 秒结束，停止按钮继续可点击。

重启、连接代次或可信来源失效后恢复未知，不恢复旧估计、不重放控制。电机可脱离系统手动操作，所有时间估计都带推断来源。

保留各房间自己的按键布局、模块逻辑 ID 和通道。方向、停止校准与各方向行程独立登记；未校准或未配置的值保持未知。已登记的书房、画室约 10 秒参数保留为这两台电机的估计依据，其余窗帘不复制该值。

已从原 12 控制器／12 代理关系生成 12 份本地迁移计划；现有两台参数和布局保留，另外十台没有新增校准、行程或 LED 映射。原剩余 24 个停止条件、11 个运动条件及其子树、变量和非窗帘动作继续逐节点处置。统一操作模型获批不等于这些完整原程序已经审核完成；原墙面板与 Control4 的执行归属保持既有切换门槛。

现有同一核心模型的六项明确回归已在固定后端的完整 1067 项中通过，覆盖未配置不虚构到位、Written／停止提示时限、重复终态命令、中途未知起点、代次失效及按键不受 LED 状态抑制。没有新增现场验证计数。见[统一策略来源核查](evidence/stage-d-study/uniform-curtain-policy-root-check.json)。
