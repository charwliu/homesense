# 场景选择观察模式

观察模式依据已核实的按键推断外部选择，标明来源且不发送控制。它用于显式配置的外部控制观察，不承担已接管面板的执行归属；初始未知时不猜测同键结果。

## 状态机

`homesense-core::scene_observer` 只输出 `Inference`，不包含 Command、传输或规则动作。运行时为每个已审核观察组启用独立外部候选集合，初始为 `{0, 全部成员}`。按成员 k 的审核边沿把每个候选 x 映射为 `x == k ? 0 : k`：只有结果集合为单值时才发布确定的推断选择，否则发布未知。第一次按 k 得到 `{0,k}`；持续同键仍无法确定，随后不同成员 m 可使两个候选都映射到 m，从而收敛。每个结果保留原始按键、事件序号、观测时间、完整代次与流代次，以及变量预期版本供事务 CAS 使用。

HomeSense 本地选择、手动场景和 LED 清零只改变本地呈现／意图，不改变独立外部集合。核心旧数值驱动接口保留供兼容调用，生产 Admission 始终显式启用独立集合，不使用 `Snapshot::selection()` 的数值作为 EA-5 基线。集合只在当前进程及完整流内保存，不从持久推断或本地值恢复；全关也不能从未知补造外部选择 0。

持续按住和重复报文不再次切换，短松开不丢失；按下间隔受去抖约束。过期或未来报文、无法可靠解释的松开及去抖期间新按下使外部流失效，已发布推断变为未知，不能在后续时刻重放。重启、传输／配置／控制代次变化或事件缓冲缺口后，旧推断来源不能作为新一轮已知选择；已有本地选择记录仍属于本地意图，不能声明为 EA-5 状态。

这里的“推断”不证明 EA-5 已执行分支、灯光达到目标或实际 LED 状态。不能依据某组亮度匹配来补造场景选中。

## 来源存储

`scene_observation` 不可变审计记录与整数选择更新在同一 SQLite CAS 事务中提交，绑定实际变量版本。证据包括按键、序号、观测时间、互斥组、推断依据、boot 和所有代次；未知初始选择也保留 inferred 证据。重复／倒序事件和版本竞争被拒绝，不创建命令、场景或规则接受记录。

`scene_selection` 在一致读事务中返回数值和来源：只有当前完整 scope 匹配才返回推断值，否则值为未知、原证据仍保留。后续本地变量更新递增版本，旧来源不会跟随人工选择。普通 `logical_variable` 接口一律遮蔽当前版本的推断值；配置发布同样先转换为未知，不仅复制数字丢失来源。

存储入口属于进程内可信边界；现在由 Admission 验证实际反馈事件、授权、当前代次和变量 CAS，不开放为 Web 直接写入接口。数据库格式回退须恢复匹配备份，不能降写 `user_version`。
## 配置与运行

1. `scene_observation` 显式配置已审核的按键→互斥组成员及审核证据，默认禁用。启用时还要求 `external_toggle_reviews: [{"group":"…","review_evidence":"…"}]`，审核所有可观察外部写入入口及其 toggle 分支；所有组成员须有审核按键绑定，不能用单个按键或本地场景组审核替代完整外部写入清单。核验成员、面板类型与容量，拒绝与启用的 Rust 面板／长按动作重叠；普通自动规则不能触发或读取被观察的选择变量，包括展开后的场景条件。显式字面量写入仍属于本地意图。
2. Consumer 从当前反馈游标起步，只消费可信、已确认的按键事件。初始已确认按住的键先等待释放；按键状态未知不等于按住。绑定可显式选择 `trigger_edge: "pressed"` 或 `"released"`；省略字段沿用 pressed，审核为松开的源分支必须显式使用 released。松开触发必须先在当前流收到一次可接受的新鲜按下，持续按住不切换；初始按住、过期按下、断档前按下或无按下的单独松开均不触发。外部集合有歧义时保持未知，已审核异键序列可收敛。观测时间是主机接收时间，不证明远端发射时间或 EA-5 执行时刻。
3. Admission 所有者串行核验反馈租约、授权、配置／传输／控制／流代次，再以实际变量版本提交选择和不可变 inferred 证据。新本地变量更新会隔离先前已接收的旧按键，竞争失败不重新套用旧事件覆盖人工选择。
4. 断档、重连、重启或发布使旧推断失效；流失效标记不依赖队列剩余容量。事件被消费后不因等待取消或结果不确定而重放。普通变量读取继续遮蔽推断值，普通规则不能将其作为已确认输入。
5. HAP 与手动场景规划使用当前作用域的选择快照。管理 API 区分本地意图／按键推断／推断已失效／未知来源；HAP On 布尔值无法携带置信来源，不能声称家庭 App 展示推断标签。显式人工动作接受后建立新的本地意图，与旧按键证据分离。
6. 观察路径不构造灯光、窗帘、LED 指令，也不重放 EA-5 场景。初始未知不根据亮度匹配补造场景选择；未知和实际 LED 状态继续分别处理。

## 来源边界

触发边沿须按准确源声明审核，不能按事件编号猜 Press／Release。流缺口、不可观察的外部写入或来源变化使推断失效；观察清单不证明外部控制器已实际执行，也不证明灯光或 LED 达到目标。
