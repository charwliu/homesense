# 参考资料管理

本目录公开 HomeSense 协议核对笔记及 Control4 解析工具；完整设备映射与来源清单留在本机私有目录。编译、测试和运行不依赖私有工程或第三方说明书副本。

第三方产品手册、提取全文、原页截图、下载图片和原始 Control4 项目仅供本地查阅，不纳入公开源码。本地 `manifest.json` 保留来源及哈希索引；清单记录不表示原文件随仓库分发。

原始工程、解析快照、设备导出、配对、凭证及验收日志放在已忽略的私有目录。生成审核输出使用新目录并保留已有记录，不将这些输出加入 Git。

`vendor/hap` 是构建依赖，保留其源码、说明和许可证。项目公开功能与使用方式见[文档导航](../docs/README.md)。
