HopeBeauty 协议与发送说明

本页概括已登记型号的命令能力。完整编码及验证以 crates/hb-protocol 为准，模块、通道和接线见 docs/lighting-curtain-channel-map.md；原始手册及工程留在私有资料目录。

1. 传输与地址
TCP485透明传输使用二进制字节，不发送十六进制文本。串口9600 baud、8数据位、无校验、1停止位。普通帧为 AE ID CMD VALUE EE，共五字节；固定格式没有校验和。地址使用两位十六进制，00广播不在普通控制中开放。

TCP可能分片或合并帧；ID与VALUE也可能等于AE或EE，接收器按固定帧长和注册型号解释，错误字节逐步重新同步。参数查询的单字节回复和ASCII版本信息不作为普通通道状态。

2. R818-DIN PRO（八路继电器）
单路开／关：AE ID c F1/F2 EE，c=1..8。
单路翻转：AE ID (A0+c) F1 EE；状态查询：AE ID (A0+c) F2 EE。
输出反馈：AE ID (D0+c) F1/F2 EE。
整模块开／关：AE ID 00 F1/F2 EE。整模块控制不等于广播。
该PRO型号不支持整模块输出状态查询，使用八次逐路查询；不能将A8或其他型号的A0能力套用为全部查询。
接入的01–07七个R818模块启用主动反馈，周期查询作为补偿。主动反馈参数查询C7与设置C8不属于输出状态查询。

3. AD8-DIN（八路调光）
直接设定：AE ID c level EE，level为0..100整数，100是0x64，10是0x0A。
单路查询：AE ID (A0+c) F2 EE；整模块查询：AE ID A0 F2 EE。
反馈：AE ID (D0+c) level EE，整模块回复逐路D1–D8返回。
整模块设定：AE ID 00 level EE。
协议层支持B1–B8原生渐变，但已审核日常灯光配方采用直接目标亮度；查询等待按实际发送的命令类型处理，不为直接设定固定等待六秒。
AD8主动反馈参数不能从R818的C7/C8推断，状态采集保留明确查询。

4. C4-DIN PRO窗帘
升／降／停：AE ID c F1/F2/F0 EE，c=1..4，方向由逻辑窗帘校准解析。
当前接口没有可靠的运动或位置读回。行程估计从完整Written开始，独立配置开／关时间；硬件吸合／互锁参数不代替行程。
打开／关闭／停止和同向再次停止分别按审核入口处理，停止不依赖估计终态或LED颜色。

5. TS6-86六键面板
按下／释放：AE ID (D0+c) F1/F2 EE，c=1..6。
LED红／绿：AE ID c F1/F2 EE；灭灯使用经型号验证的F0编码。
背光查询C5 00，设置C6 01/02/03；工作模式查询C7 00，设置C8 01自复位／02手动。TS6参数设置依型号协议要求连发三次，不能套用到其他模块。
仅在确认手动反馈模式后由指令控制LED；无颜色读回时标记最后写出，不能把按下事件当作实际红灯。
按键编号按1 2／3 4／5 6排列，实体事件按有效按下／释放与去重规则处理。

6. 调度与反馈
每条总线使用唯一发送所有者。查询未收齐有效回复或超时之前不发送另一查询或控制，之后遵守线速占用与换向间隔。多模块灯光配方按模块发送、等待所需反馈再推进；模块全关失败仍继续关闭其余模块，并按有界策略重试失败模块。
反馈没有事务编号，匹配回复用于状态和占用管理，不能升级成严格的命令因果ACK。断线、配置及连接代次变化使旧证明失效；响应丢失或不确定结果不自动重放控制。

7. 来源与验证
不同型号的能力独立登记，GT系列的4／8路能力不自动授予R818、AD8或其他型号。地址映射、设备型号、参数与接线分别审核。软件编码／模拟、部署只读核对及现场动作证据分别保留；已完成范围见 docs/control4-takeover-checklist.md。
