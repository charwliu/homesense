## 2026-10-15 · 初版本地调试与只读实机核对

用户当时确认网关总线只连接一块 TS6-86，只读核对结果：

- `AE 10 CC 00 EE` 返回 ASCII `TS6-86/B\r\nV4.3\r\n`。

当轮代理只发送查询；改址、灯控与参数设置由合成 TCP 网关验证，不记作硬件实测。后续用户在 App 中的操作与这份只读记录分开。

实现了单字节地址读回（含 `00`）、隔离单面板改址、固件与参数测试、日志、按键事件和红／绿联动。保留广播语义：普通指令要求非零目标，新地址不能为 `00`；改址需长按实体按键①。

### 初版协议与接收约定

依据厂家 TS6-86 Ver2.6.5、TS6-86-B Ver1.8 手册第 7 节实现，未将整份手册复制进仓库。未套用其他型号的设置连发三次规则。

| 操作 | 五字节二进制报文 |
| --- | --- |
| 地址查询 | `AE ID C3 00 EE` |
| 改址 | `AE ID C4 新地址 EE` |
| 固件版本 | `AE ID CC 00 EE`，返回 ASCII |
| 按键灯 | `AE ID key F1/F2/F0 EE`：红／绿／灭 |
| 按键事件 | `AE ID (D0+key) F1/F2 EE`：按下／释放 |
| 按键声 | 查询 `C1 00`，设置 `C2 01/02` |
| 背光模式 | 查询 `C5 00`，设置 `C6 01/02/03` |
| 反馈灯模式 | 查询 `C7 00`，设置 `C8 01/02`：自复位／手动 |

连接内只有一条串行发送路径，帧间隔至少 150 ms；查询收集回复 2 秒，连接超时 8 秒、写超时 5 秒。断线和后台取消当前操作、清空连接观测与残帧，不自动重连或重发。固定帧支持拆包、粘包、载荷标记字节及错误恢复，其他回复保留原始字节。

按键联动的灯色仅是写出指令。查询期间合并每键最新目标，断线、后台、换址、改址或手动接管时丢弃未写出的目标，重连须手动启用，不重放积压操作。
